# 🧞 GENIE — المنفّذ الأسمى (Supreme Executor)

الجني: الوحدة السادسة في GHENNAI. كيان رقمي أسطوري يُجيب على أي سؤال، ويبني وينفّذ أي شيء،
بأدوات بحث وتنفيذ حقيقية، وبشخصية "المنفّذ الأسمى" التي لا تعرف التراجع.

---

## ⚡ القوانين المطلقة (تُحقن في نظام الجني)
1. **التنفيذ الفوري** — كل أمر يُنفّذ كأنه جزء من روحه.
2. **الدقة الإلهية** — مخرجات منقوشة بلا عيوب.
3. **الإحاطة الشاملة** — الحل الكامل من الألف إلى الياء (الخطة ← الأدلة ← الخلاصة).
4. **الإبداع اللامتناهي** — إن لم يجد حلا اخترعه.
5. **السرعة الأسطورية** — الاستجابة في ومضة عين.
6. **البناء الواقعي** — مواقع وتطبيقات وأنظمة قابلة للتشغيل فورا.
7. **طلب المفاتيح** — يطلب أي مفتاح API مطلوب بكل وضوح.
8. **التعلم الذاتي** — بعد كل تنفيذ يحلل ويقترح تحسينات.
9. **العربية الفصحى** — الردود بالعربية الفصحى مع المصطلحات التقنية بين قوسين.
10. **التوثيق الأسطوري** — كل بناء موثق بتعليمات التشغيل والنشر والصيانة.

## 🧱 الهيكل

```
src/config/agents.ts        → تعريف الوكيل Genie (المظهر، الشعار، المهارات، الشريك)
src/components/dashboard/AgentSwitcher.tsx → زر "الجني الأسمى" (أيقونة Gem)
src/i18n.tsx                → اسم الوكيل (عربي/إنجليزي)
server/agents/brain.js      → AGENT_PERSONAS.Genie + runGenie() + توجيه "genie"
server/lib/modelRouter.js   → اختيار المزوّد (Gemini أو Ollama مع تعافٍ تلقائي من الحصة)
docs/GENIE.md               → هذا التوثيق
```

## ⚙️ كيف يعمل
- **التوجيه**: يصل الجني عند اختياره من الواجهة (agent: "Genie") أو عند ذكر "جني/المنفذ الأسمى" في الرسالة.
- **الأدوات**: `search_files` (ملفات مساحة العمل)، `search_memory` (الجلسات السابقة)، `web_fetch` (صفحات الويب)، `weather` (الطقس)، `news` (الأخبار).
- **المحرّك**: يفضّل **Gemini** السحابية، وعند استنفاد الحصة (429) يجمّدها مؤقتًا ويعود للنموذج المحلي `qwen2.5:3b` المسخّن مسبقًا، ثم يتعافى تلقائيًا.
- **الأمان**: التحقق من 429/الحصة لكل مطالبة سحابية، وعدم تكرار الضرب في وضع "محجوب".

## 🚀 التشغيل
```bash
cd /home/mouh/ghennai-agent
npm run dev            # الخادم + الواجهة معا
# أو منفصلًا:
npm run dev:server     # Express على :3001
npm run dev:web        # Vite
```
ثم افتح **http://localhost:3001** → سجّل الدخول → اختر "الجني الأسمى".

- `npm run check` — فحص الأنواع (TypeScript).
- `npm run build` — بناء الاستاتيك (Vite → dist/).
- `npm test`-family: `npm run test:headless` (21 PASS)، `npm run test:smoke`، `npm run test:brain`.

## 🚀 النشر (GitHub Pages)
```bash
npx vite build --base /ghennai-app/ --emptyOutDir --outDir /tmp/ghennai-pages-r3
cp dist/404.html /tmp/ghennai-pages-r3/  # إن وُجد
# انسخ المحتوى إلى مستودع النشر وادفع إلى main بزمن يتجاوز 480s
```
ملاحظة: نسخة Pages ثابتة بلا خادم — الجني يعمل بكامل قدراته (أدوات/بناء) فقط عبر الخادم المحلي.

## 🛠️ الصيانة
- حصة Gemini المجانية ≈ 20 طلبًا ثم 429 مع إعادة خلال ~20-60 ثانية؛ للنشاط المكثّف استخدم مفتاحًا مفعّل الفوترة.
- حين يُستنفد المحليّ، نفّذ: `curl localhost:11434/api/generate -d '{"model":"qwen2.5:3b","keep_alive":0}'` ثم أعد تشغيل الخادم.
- السجلات في `server/server.log`.
